Harfogram — Ukrainian word lists

The Ukrainian word lists used in the game Harfogram are Modifications of the Hunspell uk_UA dictionary of the dict_uk project, release v6.8.6 (2026-09-19, hunspell-uk_UA_6.8.6.zip). That dictionary is licensed under GPL 3.0 or above, LGPL 2.1 or above and MPL 1.1; Harfogram uses it under the Mozilla Public License 1.1 (MPL-1.1.txt). The files below are the Source Code form of these Modifications, made available as required by MPL 1.1 §3.2. The rest of the application is a separate work and is not covered by this license.

Files

  • dictionary_uk.txt — the word list the game uses to validate moves (503,460 words, lowercase).
  • ai_words_uk.txt — the subset the computer opponent plays, most frequent first (70,000 words, uppercase).
  • MPL-1.1.txt — license text.

Changes made (MPL 1.1 §3.3) — 2026-10-04

  1. Expanded uk_UA.dic with the suffix rules of uk_UA.aff.
  2. Kept only entries whose stem starts with a lowercase letter (proper nouns and abbreviations removed) and that contain only Ukrainian letters and the apostrophe.
  3. Kept every stem (lemma), plus the inflected forms that also occur in the wordfreq frequency list (used offline for ranking only; no wordfreq data is included).
  4. Removed the apostrophe from words (м'ясо → мясо), as the game has no apostrophe tile. Minimum length 2. Sorted in Ukrainian alphabetical order.
  5. ai_words_uk.txt: words of dictionary_uk.txt that occur in wordfreq, ordered by frequency, first 70,000, uppercase.
