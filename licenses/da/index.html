Harfogram — Danish word lists

The Danish word lists used in the game Harfogram are Modifications of the Hunspell da_DK dictionary of Stavekontrolden, version 2.9.101 (2026-06-07), as distributed in the LibreOffice dictionaries repository. That dictionary is published under GPL 2.0, LGPL 2.1 and MPL 1.1; Harfogram uses it under the Mozilla Public License 1.1 (MPL-1.1.txt). The files below are the Source Code form of these Modifications, made available as required by MPL 1.1 §3.2. The rest of the application is a separate work and is not covered by this license.

Files

  • dictionary_da.txt — the word list the game uses to validate moves (387,161 words, lowercase).
  • ai_words_da.txt — the subset the computer opponent plays, most frequent first (22,463 words, uppercase).
  • MPL-1.1.txt — license text.

Changes made (MPL 1.1 §3.3) — 2026-10-05

  1. Expanded da_DK.dic with the prefix and suffix rules of da_DK.aff (two suffix levels via continuation classes) and added the irregular forms listed in the al: fields. No compounds were generated.
  2. Removed entries flagged FORBIDDENWORD or ONLYINCOMPOUND, stems that start with an uppercase letter (proper nouns), and stems flagged NEEDAFFIX on their own.
  3. Removed genitive forms: rules tagged +GENITIV; plural definite genitives ending in -enes; irregular forms that equal another form of the same lemma plus -s; and past participle + passive -s. The conjunction mens was kept.
  4. Removed words without a vowel (abbreviations such as tv, pc, kg), except a few interjections. Removed diacritics other than æ, ø and å (café → cafe). Kept only words of letters a–z, æ, ø, å, minimum length 2. Sorted in Danish alphabetical order.
  5. ai_words_da.txt: words of dictionary_da.txt that occur in the wordfreq frequency list (used offline for ranking only; no wordfreq data is included), ordered by frequency, uppercase.
