Harfogram — Romanian word lists

The Romanian word lists used in the game Harfogram are Modifications of the Hunspell ro_RO dictionary of the Rospell project, version 3.3.10, as distributed in the LibreOffice dictionaries repository. That dictionary is licensed under GPL 2.0, LGPL 2.1 and MPL 1.1; Harfogram uses it under the Mozilla Public License 1.1 (MPL-1.1.txt). The files below are the Source Code form of these Modifications, made available as required by MPL 1.1 §3.2. The rest of the application is a separate work and is not covered by this license.

Files

  • dictionary_ro.txt — the word list the game uses to validate moves (1,458,073 words, lowercase).
  • ai_words_ro.txt — the subset the computer opponent plays, most frequent first (32,139 words, uppercase).
  • MPL-1.1.txt — license text.

Changes made (MPL 1.1 §3.3) — 2026-10-05

  1. Expanded ro_RO.dic with the suffix and prefix rules of ro_RO.aff (prefixes applied to the stem and to its suffixed forms).
  2. Removed stems that start with an uppercase letter (proper nouns and abbreviations).
  3. Removed diacritics (ă, â → a; î → i; ș/ş → s; ț/ţ → t), as the game has no accented tiles. Kept only words of letters a–z, minimum length 2; removed words without a vowel (abbreviations), except a few interjections. Sorted alphabetically.
  4. ai_words_ro.txt: words of dictionary_ro.txt that occur in the wordfreq frequency list (used offline for ranking only; no wordfreq data is included), ordered by frequency, uppercase.
